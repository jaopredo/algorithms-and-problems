## Exercício: Implementação do BFS para Caminho Mínimo

O objetivo é **implementar a adaptação do algoritmo BFS** (Busca em Largura) para encontrar o **caminho mais curto** (em número de arestas) entre um vértice de origem e todos os vértices acessíveis por ele.

---

### ⏱️ Complexidade

A complexidade de tempo da adaptação do algoritmo BFS é:

$$
O(|V| + |E|)
$$

Onde:
* $|V|$ é o número de vértices.
* $|E|$ é o número de arestas.
